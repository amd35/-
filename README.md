# Connect+ — دردشة واتصالات صوتية وفيديو

تطبيق اجتماعي حقيقي (سيرفر + قاعدة بيانات + واجهة) للدردشة والمكالمات الصوتية ومكالمات الفيديو
مع محفظة كونز، محاولات مجانية يومية، توزيع أرباح، شحن، ولوحة تحكم إدارية.

> هذا المستودع يحتوي **الكود المصدري الكامل** للتطبيق. التشغيل في بيئة المعاينة يتم عبر
> ملف Compose الموجود في مستودع البيئة (`$BASE44_CONFIG_ROOT/docker-compose.base44.yml`)،
> وليس داخل المستودع، حتى لا تختلط إعدادات البيئة بكود التطبيق.

## البنية

| الطبقة | التقنية | المسار |
| --- | --- | --- |
| الواجهة (Android-first / PWA) | React 18 + TypeScript + Vite | `web/` |
| السيرفر | Node.js 22 + TypeScript + Express | `server/` |
| قاعدة البيانات | PostgreSQL 16 | `server/src/schema.sql` |
| الاتصالات الفورية | WebSocket (ws) — إشارات WebRTC + الدردشة + الإشعارات | `server/src/realtime.ts` |
| المكالمات الصوتية/الفيديو | WebRTC (بث حقيقي بين الطرفين) | `web/src/lib/call.tsx` |
| لوحة الإدارة | React (مسار `/admin`) | `web/src/pages/Admin.tsx` |

### الخدمات

- `web` — واجهة التطبيق على المنفذ **3000** (هو نقطة الدخول العامة الوحيدة).
- `api` — REST + WebSocket على المنفذ **4000** داخلياً، ومنفذ **8000** للوصول المباشر (webhooks / فحص API).
- `db` — PostgreSQL 16 مع حجم بيانات دائم.

الواجهة تصل إلى الـ API عبر نفس الأصل (proxy من Vite لـ `/api` و`/ws` و`/uploads`)، لذلك
الجلسات والكوكيز تعمل بدون إعداد CORS.

## التشغيل

```bash
docker compose --project-name app \
  --project-directory "$BASE44_PROJECT_ROOT" \
  -f "$BASE44_CONFIG_ROOT/docker-compose.base44.yml" up -d
```

- كل خدمة تثبّت الاعتماديات عند الإقلاع (`npm ci`) ثم تشغّل وضع التطوير مع إعادة التحميل
  (`tsx watch` للسيرفر، `vite` للواجهة) من الكود المرتبوط مباشرة.
- مخطط قاعدة البيانات يُطبَّق تلقائياً عند إقلاع السيرفر (idempotent)، مع بذور الإعدادات والباقات.
- حساب الإدارة يُنشأ/يُحدَّث تلقائياً من السر `ADMIN_PASSWORD` (اسم المستخدم `admin`).

### الأسرار المطلوبة

| الاسم | الاستخدام |
| --- | --- |
| `SECRET_KEY` | توقيع JWT للجلسات (إلزامي) |
| `ADMIN_PASSWORD` | كلمة مرور لوحة الإدارة (إلزامي) |
| `GOOGLE_CLIENT_ID` | اختياري — تفعيل تسجيل الدخول بـ Google |
| `SMS_PROVIDER_URL` / `SMS_PROVIDER_KEY` | اختياري — إرسال رمز OTP برسالة حقيقية |
| `SMTP_URL` | اختياري — إرسال رابط استعادة كلمة المرور بالبريد |
| `PAYMENT_WEBHOOK_SECRET` | اختياري — تفعيل تأكيد الدفع الآلي من مزود (HMAC-SHA256) |
| `ZAINCASH_MERCHANT_ID` / `FASTPAY_MERCHANT_ID` | اختياري — إظهار بوابات الدفع المحلية |

بدون مزوّد SMS/بريد، يعمل التطبيق لكن يُعاد رمز OTP/رابط الاستعادة داخل استجابة السيرفر
في وضع المعاينة فقط (`BASE44_PREVIEW_MODE=1`) لتتمكن من إكمال التسجيل.

## ما هو منفّذ فعلياً

| الميزة | الحالة |
| --- | --- |
| تسجيل/دخول بالبريد أو الهاتف + OTP + استعادة كلمة المرور + حذف الحساب | ✅ حقيقي (توصيل SMS/بريد يحتاج مزوّد) |
| محاولات مجانية 5/5 يومياً (صوت+فيديو مشتركة) بتوقيت بغداد | ✅ على السيرفر، لا يعتمد على ساعة الهاتف |
| مكالمات صوتية/فيديو بين مستخدمين | ✅ WebRTC حقيقي + إشارات عبر WebSocket |
| خصم 100 كونز/دقيقة + حجز مسبق + تسوية الثواني + إيقاف عند نقص الرصيد | ✅ معاملات قاعدة بيانات |
| توزيع أرباح 50/50 قابل للتعديل | ✅ سجل أرباح للمستخدم وللإدارة |
| شحن كونز + تأكيد من السيرفر (إدارة أو webhook موقّع) | ✅ لا إضافة رصيد قبل التأكيد |
| سحب الأرباح (طلب/موافقة/رفض مع إرجاع) | ✅ |
| دردشة نصية + صور + ملفات + حالة قراءة + حظر/إبلاغ | ✅ |
| سجل مكالمات (صادرة/واردة/فائتة/صوت/فيديو/التكلفة) | ✅ |
| إشعارات فورية داخل التطبيق (WS) | ✅ |
| لوحة إدارة كاملة (مستخدمون/مكالمات/أسعار/باقات/طلبات/أرباح/سحب/بلاغات/تقارير) | ✅ |
| إشعارات Push عبر Firebase (تطبيق مغلق) | ❌ غير منفّذ — يحتاج مشروع Firebase ومفاتيحه |
| تطبيق Flutter + ملف APK | ❌ غير منفّذ — هذه نسخة ويب متجاوبة (PWA) بنفس الـ API |

### ملاحظات صدق مهمة

- **الدفع**: لا توجد مفاتيح مزوّد دفع حقيقية في البيئة. التدفق المنفّذ هو: المستخدم ينشئ طلباً →
  يُعلِم بالدفع → **الإدارة تؤكد** → يُضاف الرصيد (idempotent). كما يوجد webhook موقّع
  (`POST /api/payments/webhook`) جاهز لربط أي مزوّد يوفر مفتاح توقيع.
- **المكالمات**: الوسائط تنتقل مباشرة بين المتصفحين عبر WebRTC (STUN عام). للشبكات المقيدة
  أضف TURN في `web/src/lib/call.tsx`. لا يوجد أي محاكاة: المؤقت والتكلفة والخصم كلها من السيرفر.
- **الأندرويد**: الواجهة مصممة mobile-first بدعم RTL، ويمكن تغليفها كـ APK عبر Capacitor/TWA
  دون تغيير الـ API. كود Flutter غير موجود في هذا التسليم.
