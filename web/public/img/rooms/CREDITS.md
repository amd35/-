# Credits — room background photographs

Photographs offered by the room-background picker (`app/room_backgrounds.py` on the API,
`RoomBackgroundSheet.jsx` in the web UI). The full file is served at
`/img/rooms/<slug>.jpg` and the picker thumbnail at `/img/rooms/thumbs/<slug>.jpg`.

All files come from Wikimedia Commons with a free licence (shown per file); the licence
travels with the file. No AI-generated imagery: only real, freely licensed photographs
(see `AGENTS.md`). Each file is the Commons thumbnail of the named file, resized to
1280px width (420px for the picker thumbnail) and re-encoded to JPEG — the photograph
itself is unchanged.

The contrast scrim over the photograph lives in CSS
(`.room-background-photo` in `web/src/styles.css`, section 22): the picture stays sharp
and is never blurred, so an asset can be swapped by replacing that one file.
