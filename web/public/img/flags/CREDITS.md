# Credits — country flags

Real flag images used by the country row and the country badges on the web home
page. Each file is the Wikimedia Commons thumbnail of the named file, downloaded
at 256 px width via `Special:FilePath` and used unchanged (no AI-generated art,
no emoji).

National flags are in the public domain on Commons (PD-ineligible / PD-shape —
a flag of state is not copyrightable); the Commons file page is the source of
record for each file and carries its own licence tag.
